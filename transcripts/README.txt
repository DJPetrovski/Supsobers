Drop transcripts here, one file per video, named with the YouTube video id:
  1iRzxPM1A0M.txt   or   1iRzxPM1A0M.srt   or   1iRzxPM1A0M.vtt
(A file whose name merely contains the 11-character id also works.)
.srt / .vtt keep their timestamps, so a search result can open the video at the exact moment.
Plain .txt works too; put [mm:ss] or [h:mm:ss] markers in it if you want timestamps.
Then run:  python3 scripts/build_transcripts.py
